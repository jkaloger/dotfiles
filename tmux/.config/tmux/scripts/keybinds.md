# tmux keybindings

## Windows

| Key | Action |
|-----|--------|
| `Cmd+n` / `Cmd+t` | New window |
| `Cmd+w` | Close pane |
| `Cmd+1-9` | Switch to window 1-9 |
| `Ctrl+Tab` | Next window |
| `Cmd+Shift+[` | Previous window |
| `Cmd+Shift+]` | Next window |
| `Cmd+,` | Rename window |

## Panes

| Key | Action |
|-----|--------|
| `Cmd+d` | Split horizontal |
| `Cmd+Shift+d` | Split vertical |
| `Cmd+Enter` | Toggle zoom |
| `Cmd+←/→/↑/↓` | Navigate panes |
| `Alt+Shift+h/l/u/d` | Resize panes |
| `prefix + \|` | Split horizontal |
| `prefix + -` | Split vertical |
| `prefix + >` | Swap pane forward |
| `prefix + <` | Swap pane backward |

## Sessions

| Key | Action |
|-----|--------|
| `Cmd+k` | Session picker (sesh) |
| `Cmd+j` | New worktree |
| `Cmd+Shift+n` | New session |
| `Alt+q` | Detach session |

## Other

| Key | Action |
|-----|--------|
| `Cmd+f` | Search (copy mode) |
| `Cmd+/` | This help dialog |
| `` Cmd+` `` | Quick terminal (global) |

> prefix = `Ctrl+a`
